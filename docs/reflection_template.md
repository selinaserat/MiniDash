# Personal reflection template (write 1–2 pages, export PDF)

Do not present these prompts as already completed. Write your own first-hand answers based on the implemented code and real verification.

1. **Three defects in AI output:** For three actual defects, document the original output, how you detected the issue (test/diff/manual review), and the correction.
2. **Where AI helped most and least:** Describe a concrete interaction of each type and explain why.
3. **How prompting improved:** Compare actual early and late prompts, identifying changes in scope, contracts, tests and boundaries.
4. **Decision retained by you:** Explain one design or quality decision you personally evaluated and the alternatives you considered.
5. **Limits of evidence:** State what remains unverified (such as load, concurrency, production authentication, and real road data), and explain what you would test next.

Evidence to attach or reference: tests summary, actual commit hashes, dependency-registry checks, driver demo output, and your AI_LOG.md.
